 
# Автотестирование LLM-модели llama3

Домашнее задание по автоматизированному тестированию LLM-моделей на галлюцинации, согласованность и корректность API.

## Используемые технологии

- Python 3
- pytest
- requests
- Docker и Docker Compose
- Ollama
- llama3

## Проверяемые сценарии

| Тест | Описание |
|---|---|
| `test_api.py` | Проверка HTTP-статуса и структуры ответа API Ollama |
| `test_hallucinations.py` | Проверка, что модель не подтверждает ложную предпосылку о Нобелевской премии |
| `test_consistency.py` | Проверка одинаковых ответов на три одинаковых запроса |

Для уменьшения случайности ответов используются `temperature=0` и `seed=42`.

## Требования

Для запуска необходимы:

- Python 3.10 или новее
- Docker Desktop с поддержкой Docker Compose
- Подключение к интернету для первоначальной загрузки модели
- Достаточно свободного места для модели llama3 (около 4,7 ГБ)

## Установка и запуск

### 1. Клонирование репозитория

```powershell
git clone <адрес-репозитория>
cd HW8
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 4. Запуск Ollama

Убедитесь, что Docker Desktop запущен, а порт `11434` свободен.

```powershell
.\start_ollama.ps1
```

Скрипт создаст контейнер Ollama, дождётся запуска API и загрузит модель `llama3`.

Если Ollama уже установлена и модель загружена, повторный запуск не требуется.

### 5. Запуск автотестов

```powershell
python -m pytest tests/ -v
```

## Особенности тестирования LLM

Ответы языковой модели могут отличаться даже при одинаковом запросе.

Тест на галлюцинации использует заранее известный факт и проверяет наличие ожидаемых формулировок. Такой подход не выявляет все возможные галлюцинации.

Тест на согласованность проверяет воспроизводимость ответа на одном конкретном вопросе, а не общую согласованность модели во всех ситуациях.

## Остановка Docker-контейнера

```powershell
docker compose down
```

Данные модели сохраняются в Docker volume, поэтому повторно скачивать модель обычно не потребуется.
