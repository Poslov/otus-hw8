# Автотестирование LLM-модели llama3

Домашнее задание по автоматизированному тестированию LLM-модели `llama3` на галлюцинации, согласованность ответов и корректность API.

## Используемые технологии

- Python 3.11
- pytest
- requests
- Docker и Docker Compose
- Ollama
- llama3

## Проверяемые сценарии

| Тест | Описание |
|---|---|
| `test_api.py` | Проверка HTTP-статуса и структуры JSON-ответа API Ollama |
| `test_hallucinations.py` | Проверка, что модель не подтверждает ложную предпосылку о Нобелевской премии по математике |
| `test_consistency.py` | Проверка одинаковых ответов модели на три одинаковых запроса |

Для уменьшения случайности ответов используются параметры `temperature=0` и `seed=42`.

## Требования

Для запуска необходимы:

- Python 3.11 или новее
- Docker Desktop с поддержкой Docker Compose
- Подключение к интернету для первоначальной загрузки модели
- Не менее 5 ГБ свободного места для модели `llama3`

## Установка и запуск

### 1. Клонирование репозитория

```powershell
git clone <адрес-репозитория>
cd otus-hw8
```

### 2. Создание виртуального окружения

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```powershell
python -m pip install -r requirements.txt
```

### 4. Запуск Ollama

Убедитесь, что Docker Desktop запущен и порт `11435` свободен.

Выполните команду:

```powershell
.\start_ollama.ps1
```

Скрипт автоматически:

1. Создаст и запустит Docker-контейнер `ollama-hw8`.
2. Дождётся доступности API Ollama.
3. Загрузит модель `llama3`.
4. Выведет сообщение о готовности.

При первом запуске загрузка модели может занять несколько минут.

**Параметры контейнера:**

| Параметр | Значение |
|---|---|
| Имя контейнера | `ollama-hw8` |
| Адрес API | `http://localhost:11435` |
| Модель | `llama3` |
| Docker volume | `hw8_ollama_hw8_data` |

Контейнер использует порт `11435`, чтобы не конфликтовать с другой установкой Ollama на стандартном порту `11434`.

### 5. Запуск автотестов

```powershell
python -m pytest tests/ -v
```

По умолчанию автотесты обращаются к API Ollama по адресу `http://localhost:11435`.

## Настройка адреса API

При необходимости можно использовать другую установленную Ollama.

Например, для запуска тестов с Ollama на стандартном порту `11434` выполните:

```powershell
$env:OLLAMA_BASE_URL = "http://localhost:11434"
python -m pytest tests/ -v
```

Для возврата к адресу по умолчанию удалите переменную:

```powershell
Remove-Item Env:OLLAMA_BASE_URL
```

## Особенности тестирования LLM

Ответы языковых моделей могут отличаться даже при одинаковых запросах.

**Тест на галлюцинации** использует вопрос с заведомо ложной предпосылкой. Модель должна указать, что Альберт Эйнштейн не получал Нобелевскую премию по математике.

Тест проверяет наличие ожидаемых формулировок в ответе. Это упрощённая проверка, которая не гарантирует выявление всех галлюцинаций.

**Тест на согласованность** отправляет модели один вопрос три раза и сравнивает полученные ответы.

Использование `temperature=0` и `seed=42` уменьшает случайность генерации, но не гарантирует полной воспроизводимости.

**Тест API** проверяет HTTP-статус, наличие ожидаемых полей JSON и завершение генерации.

## Остановка Docker-контейнера

Для остановки и удаления контейнера домашнего задания выполните:

```powershell
docker compose down
```

Данные модели сохраняются в отдельном Docker volume. При следующем запуске повторная загрузка модели обычно не требуется.

Существующие контейнеры Ollama, не относящиеся к этому проекту, команда не затрагивает.
